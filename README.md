# PROJETO A.T.L.A.S.

Projeto A.T.L.A.S. é um shoot ’em up incremental ambientado em um futuro onde o lixo tomou conta dos oceanos e corrompeu as antigas Guardiãs, criaturas responsáveis por proteger e purificar as águas. Como agente da A.T.L.A.S., você explora mares infestados de Animalixos — criaturas marinhas fundidas com lixo — limpando-as e reciclando os resíduos para obter recursos. Use seus ganhos para melhorar o submarino, alcançar novas áreas, salvar as Guardiãs e reconstruir o ecossistema dos oceanos.

## AVISOS
Esta versão do jogo se encontra em versão alpha, não contendo muito de suas mecânicas principais, polimento e podendo apresentar bugs.

## ORIENTAÇÕES PARA INSTALAÇÃO
Passo a passo para playtest (SOMENTE WINDOWS):
- Descompacte o arquivo "Projeto ATLAS 0.1.zip";
- Navegue até encontrar "PROJETO A.T.L.A.S.exe";
- Clique duas vezes sobre o executavel;
- Ignore as mensagens de erro e inicie o game.

## CONTROLES
- W A S D - Movimentação;
- Click Esquerdo do mouse - Atirar projéteis;
- R - Voltar ou reiniciar o jogo.

## GAMEPLAY
Seu objetivo é navegar no oceano, desviando das rochas marinhas, atirando projeteis nos animalixos e coletando os Eco-créditos antes que o timer zere!

## GUI
- Barra de vida;
- Eco-créditos coletados;
- Oxigenio sobrando.
